# Spendvizo

### Personal Expense Tracker

Spendvizo is a personal finance website that helps users record income, manage daily expenses and track their monthly budgets.

I developed this project as a personal web development project to practise building interactive websites and solving everyday problems with technology.

## Features

- Add, edit and delete transactions
- Track income and expenses
- Search transactions by description
- Filter transactions by amount
- Filter transactions by category
- View monthly financial summaries
- Category-wise expense analysis
- Monthly budget tracking
- Interactive charts
- Export transaction data to CSV
- Backup and restore data
- Dark and light themes
- Responsive design

 ## Technologies Used

1. HTML5 – Website Structure
2. CSS3 – Styling and Responsive Design
3. JavaScript (ES6+) – Functionality and Interactivity
4. LocalStorage API – Browser-based Data Storage

## How It Works

Spendvizo runs directly in a web browser. Users can start recording transactions without creating an account.

Transaction data is saved in the browser's LocalStorage.

## Privacy

- No login or registration required.
- No server-side database.
- Transaction data stays in the user's browser.
- Data does not automatically synchronise between devices.

## Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
